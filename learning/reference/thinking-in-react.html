Thinking in React

UI = f(props, state). Guarde o mínimo; derive o resto no render.

Lição 01react.dev/learn/thinking-in-react

Os 5 passos

  1. Hierarquia: desenhe caixas no mockup; um componente = uma responsabilidade.
  2. Versão estática: só props, zero state. Dados descem (one-way data flow).
  3. Estado mínimo e completo: DRY; compute o resto sob demanda.
  4. Onde o estado mora: ancestral comum mais próximo de quem o renderiza.
  5. Inverse data flow: o dono passa setters como callback props (onXChange).
